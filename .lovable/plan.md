# Portfolio Website for Donato Machado Santos

A modern, dark-mode, tech-inspired portfolio website with sleek animations, glowing accents, and a premium corporate feel — inspired by the reference image.

---

## 🎨 Design Direction

- **Dark mode** primary background (#0D0D0D / #111111)
- **Electric yellow/gold accent** color (matching the reference image style)
- Clean sans-serif typography with strong hierarchy
- Glassmorphism cards with hover glow effects
- Smooth scroll animations and micro-interactions
- Sticky navigation bar with smooth section scrolling
